# GSP345 – Automating Infrastructure on Google Cloud with Terraform: Challenge Lab

## Known lab traps (read first)

1. Check after every task, before starting the next one. Each checkpoint looks at what exists at that moment. Task 5 deletes the third instance, so Task 4 must be checked first.
2. Big pastes get garbled in Cloud Shell. Paste one block at a time and wait for the prompt to come back.
3. After installing Terraform, the same terminal can keep showing the "install terraform" message. Open a new Cloud Shell tab (+ next to the cloudshell tab) or run `hash -r`.
4. The imported instances must match exactly, or Terraform replaces them instead of updating them. The Setup block reads the real machine type and boot image from the existing VMs, so you don't type them.
5. `#!/bin/bash` contains a `!`, which Cloud Shell can treat as a history command when you paste ("event not found"). The blocks start with `set +H` to prevent that.
6. The checker lags. If a check shows 0 right after a successful apply, wait 30–60 seconds and click again.

## Install Terraform – follow the lab

Do the lab's "Prerequisites > Install Terraform" step exactly as written: click the copy button, paste it, run it, then run `terraform --version`.

If it still prints "Follow the instructions ... to install terraform", open a new Cloud Shell tab or run:

```bash
hash -r
terraform --version
```

## Setup – your lab's names

Your lab instructions show three names that are different for every student (highlighted in the task text):

- Bucket Name in Task 3
- Instance Name in Task 4
- VPC Name in Task 6

Replace the XXXXXX parts on the first three lines with your names. Everything else is detected automatically: zone, region, project, machine type and boot image.

```bash
echo tf-bucket-XXXXXX > ~/bucket
echo tf-instance-XXXXXX > ~/instance3
echo tf-vpc-XXXXXX > ~/vpc
gcloud config get-value project > ~/project
gcloud compute instances list --filter="name=tf-instance-1" --format="value(zone.basename())" > ~/zone
cat ~/zone | rev | cut -d- -f2- | rev > ~/region
gcloud compute instances describe tf-instance-1 --zone=`cat ~/zone` --format="value(machineType.basename())" > ~/mtype
gcloud compute disks describe tf-instance-1 --zone=`cat ~/zone` --format="value(sourceImage)" > ~/image
head ~/bucket ~/instance3 ~/vpc ~/project ~/zone ~/region ~/mtype ~/image
```

Check that all eight values print and none are empty.

## Task 1 – Create the configuration files

```bash
cd ~
mkdir -p modules/instances modules/storage
touch modules/instances/instances.tf modules/instances/outputs.tf
touch modules/storage/storage.tf modules/storage/outputs.tf

cat > variables.tf <<EOF
variable "region" {
  default = "`cat ~/region`"
}
variable "zone" {
  default = "`cat ~/zone`"
}
variable "project_id" {
  default = "`cat ~/project`"
}
EOF
cp variables.tf modules/instances/variables.tf
cp variables.tf modules/storage/variables.tf

cat > main.tf <<'EOF'
terraform {
  required_providers {
    google = {
      source  = "hashicorp/google"
      version = "~> 6.0"
    }
  }
}

provider "google" {
  project = var.project_id
  region  = var.region
  zone    = var.zone
}
EOF
terraform init
```

No checkpoint for Task 1.

## Task 2 – Import infrastructure

Block 1 – module reference and instance configuration:

```bash
set +H
cd ~
cat >> main.tf <<'EOF'

module "instances" {
  source = "./modules/instances"
}
EOF

cat > modules/instances/instances.tf <<EOF
resource "google_compute_instance" "tf-instance-1" {
  name         = "tf-instance-1"
  machine_type = "`cat ~/mtype`"
  zone         = var.zone

  boot_disk {
    initialize_params {
      image = "`cat ~/image`"
    }
  }

  network_interface {
    network = "default"
  }

  metadata_startup_script = <<-EOT
        #!/bin/bash
    EOT
  allow_stopping_for_update = true
}

resource "google_compute_instance" "tf-instance-2" {
  name         = "tf-instance-2"
  machine_type = "`cat ~/mtype`"
  zone         = var.zone

  boot_disk {
    initialize_params {
      image = "`cat ~/image`"
    }
  }

  network_interface {
    network = "default"
  }

  metadata_startup_script = <<-EOT
        #!/bin/bash
    EOT
  allow_stopping_for_update = true
}
EOF
grep -E "machine_type|image|bash" modules/instances/instances.tf
terraform init
```

Block 2 – import and apply:

```bash
cd ~
terraform import module.instances.google_compute_instance.tf-instance-1 projects/`cat ~/project`/zones/`cat ~/zone`/instances/tf-instance-1
terraform import module.instances.google_compute_instance.tf-instance-2 projects/`cat ~/project`/zones/`cat ~/zone`/instances/tf-instance-2
terraform apply -auto-approve
```

The apply should say "updated in-place", not "replaced".

## Task 3 – Configure a remote backend

Block 1 – create the bucket through the storage module:

```bash
cd ~
cat > modules/storage/storage.tf <<EOF
resource "google_storage_bucket" "storage-bucket" {
  name                        = "`cat ~/bucket`"
  location                    = "US"
  force_destroy               = true
  uniform_bucket_level_access = true
}
EOF

cat >> main.tf <<'EOF'

module "storage" {
  source = "./modules/storage"
}
EOF
terraform init
terraform apply -auto-approve
```

Block 2 – use the bucket as the backend and migrate the state:

```bash
cd ~
cat >> main.tf <<EOF

terraform {
  backend "gcs" {
    bucket = "`cat ~/bucket`"
    prefix = "terraform/state"
  }
}
EOF
terraform init -migrate-state -force-copy
gcloud storage ls -r gs://`cat ~/bucket`
```

You should see `terraform/state/default.tfstate`.

## Task 6 – Use a module from the Registry

Block 1 – create the VPC with the Registry module:

```bash
cd ~
cat >> main.tf <<EOF

module "vpc" {
  source  = "terraform-google-modules/network/google"
  version = "10.0.0"

  project_id   = var.project_id
  network_name = "`cat ~/vpc`"
  routing_mode = "GLOBAL"

  subnets = [
    {
      subnet_name   = "subnet-01"
      subnet_ip     = "10.10.10.0/24"
      subnet_region = var.region
    },
    {
      subnet_name   = "subnet-02"
      subnet_ip     = "10.10.20.0/24"
      subnet_region = var.region
    }
  ]
}
EOF
terraform init
terraform apply -auto-approve
```

Block 2 – move the instances onto the new subnets:

```bash
cd ~
sed -i "/\"tf-instance-1\" {/,/^}/ s|network = \"default\"|network    = \"`cat ~/vpc`\"\n    subnetwork = \"subnet-01\"|" modules/instances/instances.tf
sed -i "/\"tf-instance-2\" {/,/^}/ s|network = \"default\"|network    = \"`cat ~/vpc`\"\n    subnetwork = \"subnet-02\"|" modules/instances/instances.tf
grep -E "resource|network" modules/instances/instances.tf
terraform apply -auto-approve
```
